
# BLACK SHINE DETAILING – Fahrzeugaufbereitung

BLACK SHINE DETAILING ist ein fiktives Webdesign-Demoprojekt
von MAVESSO für einen Fahrzeugaufbereitungsservice.

Die Website kombiniert eine hochwertige Schwarz-Gold-Optik
mit übersichtlichen Leistungsbereichen, Preispaketen und
einer klar strukturierten Kontaktsektion.

## Live-Demo

🌐 https://mavesso.github.io/black-shine-detailing/

## Projektübersicht

- **Projekt:** BLACK SHINE DETAILING
- **Branche:** Fahrzeugaufbereitung / Autopflege
- **Kategorie:** Unternehmenswebsite / Onepager
- **Technologien:** HTML5, CSS3
- **Design:** Responsive Webdesign
- **Status:** Fiktives Demoprojekt

## Funktionen und Gestaltung

- Großflächiger Hero-Bereich mit Fahrzeugmotiv
- Individuelles Schwarz-Gold-Design
- Übersichtliche Darstellung von sieben Leistungen
- Vier Preispakete mit hervorgehobener Premium-Option
- Zusätzliche Leistungen mit Preisübersicht
- Responsive Darstellung für Desktop, Tablet und Smartphone
- Navigation zu den einzelnen Seitenbereichen
- Kontaktbereich als beispielhafte Gestaltung ohne aktive Terminbuchung

## Technische Umsetzung

Die Website wurde mit HTML und CSS umgesetzt.

CSS Grid und Flexbox sorgen für eine übersichtliche
Darstellung der Inhalte auf unterschiedlichen Geräten.

Über Media Queries wurde das Layout für Tablets
und Smartphones angepasst.

## Projektziel

Ziel war die Entwicklung eines hochwertigen
Internetauftritts für einen lokalen Dienstleister.

Der Fokus lag auf einer starken visuellen Identität,
einer übersichtlichen Leistungspräsentation und
einer einfachen Benutzerführung.

## Hinweis

BLACK SHINE DETAILING ist eine fiktive Marke.

Die dargestellten Dienstleistungen und Preise
dienen ausschließlich der Demonstration eines
Webdesign-Konzepts.

Es werden keine Fahrzeugaufbereitungen oder
Terminbuchungen angeboten.
